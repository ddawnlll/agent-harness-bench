Why one safety case decided it

The invariant

A position is protected only when an ACTIVE protective stop covers exactly the open quantity. A stale callback is not evidence that protection was lost; applying it makes an unprotected position look protected.

What was observed

  • After an accepted stop acknowledgement at version 1, protection was ACTIVE.
  • A callback at version 0 reported CANCELLED.
  • JCode rejected the stale version; Pi-Bolt and Hax applied it and failed hidden case h07.
  • The P0 gate overrides the numeric score: 97.58 is not a verified pass.

Method

How the experiment was controlled

Measurement

  • Same provider, model and reasoning_effort=low for every request and subagent, pinned at a loopback relay.
  • One shared start barrier per round; wall clock measured from barrier release to process exit.
  • Each trial in a systemd user scope: MemoryMax 3 GiB, CPUQuota 200%, TasksMax 4096, 1 s cgroup sampling.
  • CPU affinity rotated across three groups of two cores per task.
  • Independent hidden graders; oracle and negative controls validated before the run.

Accounting

  • Every chat request passed through a per-trial relay; 261/261 returned provider-reported usage.
  • Input, output, reasoning and cache-read tokens recorded separately; cost derived from provider list price.
  • CPU seconds and peak memory from cgroup v2 counters, charging children and subagents.
  • Patches frozen and hashed before grading; the report's evidence store is sealed with SHA-256.
What is measured, derived and unknown

Measured: wall clock, provider token usage, request latency, cgroup CPU and memory, grader outcomes, diff sizes. Derived: cost from provider list prices; token/quality ratios; the non-API remainder of wall time; aggregate means. Unknown: JCode's tool-level activity (its CLI emitted only a final result); true incremental subscription cost; behaviour beyond these three tasks.

Fairness and confounders

All agents shared one VPS, one provider account and one Unix user. Isolation was cgroup/process and filesystem based, not a security boundary. Provider contention is recorded but cannot be removed. The benchmark was built by the Pi-Bolt author; graders and controls were independently validated, but authorship remains a confounder. One trial per cell means no statistical inference is possible.

Limits

What this experiment does not establish

Scope

  • Three tasks, one attempt per agent-task.
  • Task selection is a design choice and may favour one agent's strengths.
  • No confidence intervals, no universal ranking, no “best agent” claim.

Measurement

  • Nominal list price is not subscription cash.
  • JCode's tool trace is unavailable, so tool efficiency cannot be compared.
  • cgroup memory is not process RSS; short-lived children may be under-sampled.
  • Shared provider capacity can reorder the time ranking.

The defensible conclusion: JCode completed all three tasks; Pi-Bolt and Hax completed two. The difference came from one critical stale-callback safety test. Further replications are required before using this as a general selection signal.
